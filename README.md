# text-extractor

Open-source alternative to the PowerToys/Snipping Tool text extractor, based on RapidOCR.

### Why?

Because the Snipping Tool text extractor doesn't like it when the selection is too small, and the PowerToys one recommends using the Snipping Tool one.
